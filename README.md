# Student Management System – SQL Project

This project demonstrates basic SQL skills, including database creation, table design, data insertion, and query writing. The goal is to manage student, course, and enrollment records.

## 📂 Features
- Create and manage student records
- Manage courses offered
- Handle student enrollments
- Run queries to generate insights

## 🛠 Technologies Used
- MySQL (or any standard RDBMS)
- SQL (DDL, DML, SELECT queries)

## 📁 Files
- `student_management.sql` – Contains schema and data
- `sample_queries.sql` – Sample queries for practice and demo

## ✅ Sample Queries
- List all students enrolled in a specific course
- Count students per course
- Show course enrollment details

## 📎 How to Run
1. Open MySQL Workbench or any SQL tool.
2. Run the `student_management.sql` script.
3. Run queries from `sample_queries.sql`.
